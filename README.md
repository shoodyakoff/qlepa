# Qlepa

Qlepa помогает собрать карусель для Instagram или Telegram из одного текстового файла. Вы пишете идею поста, добавляете референсы, смотрите превью и получаете готовые PNG-слайды в формате 4:5.

Проект работает локально на вашем компьютере. Личные фото, сгенерированные картинки и финальные PNG не попадают в git, а сам проект никуда их не загружает. Если вы работаете через Codex или Claude, фото попадут в чат только когда вы сами их туда отправите.

Если локальная папка у вас называется `images-codex`, это нормально. Переименовывать папку не нужно: публичное имя проекта теперь `Qlepa`.

## Что нужно от вас

Для первого запуска подготовьте:

- имя или название бренда;
- публичный ник, например `@your_handle`;
- темы, про которые вы пишете;
- для кого вы пишете;
- тон текста: спокойно, дерзко, экспертно, разговорно и так далее;
- режим обложки: с вашим фото или без вашего фото;
- если нужна обложка с вами: фото лица;
- если нужна обложка с вами: фото в полный рост или по пояс;
- опционально: картинку-референс стиля;
- идею первого поста или черновик текста.

Фото лица и тела нужны только для режима обложки с вами. Если выбираете обложку без вашего фото, эти два файла можно не готовить.

Если вы выбрали обложку с вами, фото можно отправить прямо в чат Codex или Claude. Агент сам сохранит их в нужные папки.

## Первый запуск

Установите зависимости:

```bash
npm exec -- pnpm install
```

Проверьте проект и запустите онбординг:

```bash
npm run start
```

Если у вас установлен `pnpm`, можно так:

```bash
pnpm install
pnpm start
```

Команда `start` напечатает, что нужно прислать, проверит папки проекта и закончит статусом:

- `READY TO RUN` — можно работать;
- `NOT READY` — нужно исправить строки с `FAIL`;
- `WARN` по фото — нормально, если вы выбрали обложку без вашего фото или ещё не добавили референсы.

## Как работать через Codex или Claude

После установки откройте проект в Codex или Claude и вставьте:

```text
Прочитай README.md, docs/chat-onboarding.md, docs/agent-dialogue.md и AGENTS.md.
Онборди меня в Qlepa.
Спроси только то, чего не хватает для моего бренда и референсов.
Оставь стандартные локальные шрифты, если я сам не попрошу поменять типографику.
Когда всё будет готово, запусти npm run start и скажи: можно делать карусель, пришли идею поста или черновик.
```

Дальше отправьте ответы и изображения в чат. Агент:

1. выберет режим обложки: с вашим фото или без вашего фото;
2. сохранит фото в приватные папки, если вы выбрали режим с вами;
3. обновит брендовые настройки;
4. проверит проект;
5. попросит идею первого поста;
6. поможет собрать превью и финальные PNG.

## Режим обложки

Обложка — это первый слайд поста, обычно `01-cover.png` в папке результата. Её не нужно отдельно хранить или вручную собирать заранее: Qlepa собирает обложку вместе со всеми слайдами поста.

Есть два режима:

- без вашего фото — обложка строится на тексте, графике, фоне или сцене; фото лица и тела не нужны;
- с вашим фото — используется дефолтный режим референсов: `face.jpg` для лица и `body.jpg` для фигуры/позы.

Референс стиля `style.jpg` можно добавить в обоих режимах, если хотите показать атмосферу, композицию или визуальный пример.

## Куда складываются файлы

Приватные фото для режима обложки с вами:

```text
assets/face-refs/face.jpg
assets/face-refs/body.jpg
assets/face-refs/style.jpg
```

`face.jpg` и `body.jpg` нужны только если хотите генерировать себя на обложке или слайдах. `style.jpg` можно не добавлять.

Исходные сгенерированные картинки, которые могут использоваться внутри обложки или слайдов:

```text
assets/generated/
```

Готовые PNG после сборки:

```text
posts/<post-name>/out/
```

Например, финальная обложка будет лежать не в `assets/generated/`, а в папке поста как `posts/<post-name>/out/01-cover.png`.

Эти папки игнорируются git. Не кладите личные фото в другие места проекта.

## Первый пост

Пример лежит здесь:

```text
posts/starter-post/post.md
```

Можно использовать его как подсказку по формату. Для нового поста лучше создать отдельную папку:

```text
posts/my-first-post/post.md
```

Если работаете через Codex или Claude, попросите агента создать папку и файл за вас.

## Превью и экспорт

Посмотреть карусель в браузере:

```bash
npm run carousel -- preview posts/starter-post
```

Собрать PNG:

```bash
npm run carousel -- build posts/starter-post
```

Для своего поста замените `posts/starter-post` на путь к своей папке.

## Подготовка картинки для обложки или сцены

Проект пока не вызывает генерацию картинок сам. Если посту нужна картинка для обложки или внутреннего слайда, Qlepa готовит промпт, считает кеш и говорит, куда сохранить исходный PNG.

Пример:

```bash
npm run carousel -- gen-photo editorial "creator at a clean desk reviewing carousel thumbnails" --no-wait
```

Команда покажет английский промпт и путь вида:

```text
assets/generated/<hash>.png
```

Это не финальная обложка. Это исходная картинка, которую Qlepa потом вставит в первый слайд или другой слайд и соберёт финальные PNG в `posts/<post-name>/out/`.

Если выбран режим обложки с вами, перед такой генерацией нужны `assets/face-refs/face.jpg` и `assets/face-refs/body.jpg`. Если выбран режим без вашего фото, эти файлы не нужны.

## Что можно не трогать

В первом запуске не нужно менять:

- `brand/fonts/` — локальные шрифты уже лежат в проекте;
- `brand/prompts/` — там базовые промпты для картинок;
- `templates/` — шаблоны слайдов;
- `src/` и `tests/` — код и проверки.

Обычно достаточно настроить:

- `brand/tokens.ts` — имя, ник, цвета, подписи;
- `brand/voice.md` или приватный `brand/voice.local.md` — голос автора;
- `assets/face-refs/` — ваши референсы, только если нужен режим с вашим фото;
- `posts/<post-name>/post.md` — текст поста.

## Полезные команды

```bash
npm run start
npm run carousel -- preview posts/starter-post
npm run carousel -- build posts/starter-post
npm run carousel -- gen-photo editorial "scene description" --no-wait
npm run test
```

Если у вас установлен `pnpm`:

```bash
pnpm start
pnpm carousel preview posts/starter-post
pnpm carousel build posts/starter-post
pnpm test
```

## Что безопасно отправлять другому человеку

В репозитории можно хранить код, шаблоны, шрифты, промпты и пример `posts/starter-post/post.md`.

Не коммитьте:

- настоящие фото лица и тела;
- сгенерированные картинки из `assets/generated/`;
- финальные PNG из `posts/**/out/`;
- приватные посты;
- `.env`;
- `brand/voice.local.md`.
