# Онбординг через чат

Этот файл нужен агенту Codex или Claude. Человек не должен руками искать папки и раскладывать файлы по проекту.

## Первое сообщение

Попросите человека вставить в Codex или Claude:

```text
Прочитай README.md, docs/chat-onboarding.md, docs/agent-dialogue.md и AGENTS.md.
Онборди меня в Qlepa.
Спроси только то, чего не хватает для моего бренда и референсов.
Оставь стандартные локальные шрифты, если я сам не попрошу поменять типографику.
Когда npm run start покажет READY TO RUN, объясни, что это только техническая готовность репозитория, а не готовность делать посты. Спроси недостающие данные бренда, ТГ-канал, tone of voice и фото/режим обложки. Если бренд уже настроен, попроси идею поста или черновик.
```

## Публичное поведение агента

Отвечайте человеку по-русски.

Не показывайте пользователю служебные названия внутренних навыков, режимов, tool calls или workflow. Если ваша среда требует такие механики, используйте их молча.

Если человек пишет `старт`, `/start` или `start`, считайте это согласием начать рабочий онбординг Qlepa: прочитайте этот файл, проверьте готовность через `npm run start`, спросите недостающие данные бренда и референсы, а затем переходите к первому посту.

`/start`, `start`, `старт` — один и тот же пользовательский intent.

Если человек попросил только установить репозиторий, финальное сообщение после установки должно быть:

```text
Готово. Если хотите начать работу, напишите в чат: старт.
```

## Что спросить у человека

Спросите одним коротким сообщением:

```text
Пришлите:
1. Имя или название бренда.
2. Публичный ник.
3. Ссылку на ТГ-канал или основной канал публикации.
4. Главные темы.
5. Для кого вы пишете.
6. Тон и voice: как вы обычно пишете, какие слова любите и какие нельзя.
7. Цвета, если они есть. Если нет, оставлю стандартные.
8. Режим обложки: с вашим фото или без вашего фото.
9. фото лица.
10. фото по пояс или в полный рост.
11. Если не хотите обложку с собой, вместо фото напишите: без моего фото.
12. Опционально: референс стиля.
```

На первом запуске не спрашивайте про шрифты. Используйте локальные шрифты из `brand/fonts/`, если человек сам не попросил другое.

## Что делает агент

После ответов и изображений:

1. Фиксирует режим обложки:

```text
без вашего фото
с вашим фото
```

2. Если выбран режим с вашим фото, сохраняет приватные референсы:

```text
assets/face-refs/face.jpg
assets/face-refs/body.jpg
assets/face-refs/style.jpg
```

`face.jpg` и `body.jpg` нужны только для режима с вашим фото. `style.jpg` можно использовать в любом режиме.

3. Обновляет настройки бренда:

```text
brand/tokens.ts
brand/voice.md
```

Если голос автора приватный, создаёт локальный файл:

```text
brand/voice.local.md
```

Этот файл игнорируется git.

4. Не трогает без просьбы:

```text
brand/fonts/
brand/prompts/
templates/
src/
tests/
```

5. Запускает:

```bash
npm run start
```

6. Если команда заканчивается `READY TO RUN`, не говорит, что можно делать посты. Сначала объясняет:

```text
READY TO RUN — это только техническая готовность репозитория. Это не значит, что Qlepa знает бренд, tone of voice, ТГ-канал или фото.
Сначала соберите недостающие данные бренда и референсы. Если бренд уже настроен, пришлите идею поста или черновик текста.
```

## Если чат не умеет отдавать файлы

Если Codex или Claude видит изображения как файлы, скопируйте их в `assets/face-refs/`.

Если чат не даёт доступ к вложениям, попросите человека прислать локальные пути к картинкам и скопируйте их сами. Человек всё равно не должен искать папки проекта вручную.

## Первый пост

Формат примера:

```text
posts/starter-post/post.md
```

Для реального поста создайте отдельную папку:

```text
posts/<post-name>/post.md
```

Готовые PNG должны появляться здесь:

```text
posts/<post-name>/out/
```

Финальная обложка — это первый PNG поста, обычно `posts/<post-name>/out/01-cover.png`. `assets/generated/` хранит только исходные generated-картинки, если они нужны для обложки или слайда.
