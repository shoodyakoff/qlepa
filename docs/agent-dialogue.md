## Первый онбординг

```text
Прочитай README.md, docs/chat-onboarding.md, docs/agent-dialogue.md и AGENTS.md.
Онборди меня в Qlepa.
Спроси только то, чего не хватает для моего бренда и референсов.
Оставь стандартные локальные шрифты, если я сам не попрошу поменять типографику.
Когда всё будет готово, запусти npm run start и скажи: можно делать карусель, пришли идею поста или черновик.
```

## Установить репозиторий

```text
Установи Qlepa из репозитория, поставь зависимости, запусти npm run start и проверь READY TO RUN.
Если установка прошла, в финале не запускай dev-сервер без просьбы. Скажи: готово, если хотите начать работу, напишите в чат: старт.
```

## Проверить, что проект готов

```text
Прочитай README.md, docs/chat-onboarding.md и AGENTS.md.
Запусти npm run start.
Объясни простыми словами, что готово, что предупреждает WARN и что нужно прислать дальше.
Ничего в коде не меняй без моего подтверждения.
```

## Настроить мой бренд

```text
Помоги настроить Qlepa под мой бренд.
Спроси у меня:
- имя или название бренда;
- публичный ник;
- темы;
- аудиторию;
- тон текста;
- цвета, если они есть;
- режим обложки: с моим фото или без моего фото;
- если нужна обложка со мной: фото лица;
- если нужна обложка со мной: фото в полный рост или по пояс;
- опционально: референс стиля.

Сохрани мои фото в assets/face-refs/ только если я выберу режим обложки со мной.
Обнови brand/tokens.ts и brand/voice.md.
Если профиль голоса приватный, создай brand/voice.local.md.
Не коммить приватные фото, generated-картинки и готовые PNG.
```

## Создать пост

```text
Создай новую карусель из моей идеи.
Сначала прочитай docs/carousel-art-director.md, docs/reference-driven-visual-pipeline.md, docs/carousel-quality-rubric.md и docs/visual-pattern-library.md.
Используй posts/starter-post/post.md только как пример формата.
Спроси только то, без чего нельзя написать слайды.
Сохраняй рабочие заметки и референсы в private/, если они приватные.
Перед post.md сделай анализ источника, стратегию истории, визуальное направление и брифы слайдов.
После первого рендера проведи самопроверку, исправь слабые слайды и только потом собери финальные PNG.
```

## Подготовить промпт для картинки

```text
Подготовь Mode A flow для картинки к этому посту.
Запусти:
npm run carousel -- gen-photo <preset> "<scene>" --wardrobe "<wardrobe>" --no-wait
Объясни, какой промпт использовать и куда сохранить сгенерированный файл.
Уточни, что assets/generated/ хранит исходную картинку для слайда, а финальная обложка появится в posts/<post-name>/out/01-cover.png после build.
```

## Открыть превью и собрать PNG

```text
Открой превью этого поста, проверь слайды глазами и собери финальные PNG.
Сначала используй узкую команду для превью, потом build.
Первый рендер не называй финальным: проверь читаемость, повторы, визуальную конкретику и только потом экспортируй.
```
