# Кеш сгенерированных картинок

Команда `gen-photo` показывает промпт, cache key и путь, куда нужно сохранить исходную картинку для обложки или слайда:

```text
assets/generated/<hash>.png
assets/generated/<hash>.json
```

Сгенерируйте изображение через Codex image generation и сохраните PNG по указанному пути. Это не финальная обложка: финальные PNG появляются после build в `posts/<post-name>/out/`.

Для фото-обложки с человеком используйте только `gen-photo cover ...`. Alias `cover` раскрывается в `outdoor-editorial-arrow`: низкая камера, чистое синее небо, человек справа сверху, оранжевая стрелка/геометрия. Не создавайте mood-варианты обложки.

Эта папка игнорируется git. Не перезаписывайте старые кеш-файлы вручную: если меняется промпт или референсы, команда создаст новый hash.

Файлы здесь — локальный cache/source layer, не часть публичного репозитория. Новый пользователь Qlepa получает prompt presets и команду `gen-photo`, но не получает ваши PNG, роботов, сцены, лица или финальные слайды. Чтобы получить похожую сцену, нужно снова пройти Mode A flow, сгенерировать PNG через Codex-owned image generation и сохранить его по пути, который напечатает команда.
