# Приватные фото-референсы

Сюда агент сохраняет ваши личные изображения только для фото-обложки или слайдов с вами.

Для фото-обложки с вашим фото нужны:

- `face.jpg` — портрет, чтобы сохранить узнаваемость лица;
- `body.jpg` — фото в полный рост или по пояс, чтобы сохранить пропорции и позу.

Опционально:

- `style.jpg` — референс композиции в том же outdoor-arrow стиле. Он не создаёт новый режим обложки.

Если исходники пришли как `.dng`, `.heic` или другой raw-формат, агент должен сохранить рабочие JPG-копии под именами `face.jpg` и `body.jpg`. Raw-оригиналы тоже не коммитьте.

Эти файлы игнорируются git. Не коммитьте настоящие личные фото в публичный репозиторий.
